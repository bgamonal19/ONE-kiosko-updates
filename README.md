# Aggiornamenti ONE

[Scarica ONE 0.3.6](https://raw.githubusercontent.com/bgamonal19/ONE-kiosko-updates/main/apks/ONE-kiosko-security-0.3.6.apk)

Calendario mini (140×112 dp) in alto a destra, orologio centrale, app a tutta larghezza sotto. Nessuna colonna laterale riservata al calendario.

Prima dell’installazione: Amministrazione → Disattiva chiosco. Poi Cerca aggiornamenti → Installa aggiornamento. Firma stabile e impostazioni conservate. Codice sorgente privato.
